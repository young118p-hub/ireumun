# 화면 연결 지도

누르는 것마다 **어디로 가는지 / 무엇을 보여 주는지**를 적는다. 화면을 추가·변경하면 여기부터 고친다.
디자인 기준: 캔버스 시안 K (핑크 상단 + 크롬 하단, Jua + IBM Plex Sans KR).

## 원칙

1. **점수는 전부 진짜 결과다. 랜덤 숫자는 없다.**
   - 같은 입력 → 항상 같은 점수 (MBTI는 규칙표, 내 이름 케미는 서버가 저장한 결과).
   - 아직 검사를 안 했으면 점수 자리에 숫자를 쓰지 않는다. 예시 카드는 **"예시"라고 적고** 흐리게.
2. **안 만든 기능은 누를 수 없게 + "곧 열려요"**. 눌렀는데 아무 일도 없거나 빈 화면이 나오는 버튼은 두지 않는다.
3. **뒤로 가기는 항상 한 단계 전으로**. 결과에서 뒤로 가면 입력한 값이 그대로 남은 입력 화면 (고쳐서 다시 보기 쉽게).
   홈·내 결과에서 연 결과는 뒤로 가면 거기로.
5. **결제 화면(묶음 할인)** 은 묶음을 쓸 수 있을 때(결제 전 작명·진단이 하나씩)만 내 결과 탭 위에 배너로. 예전엔 홈 배너가 유일한 입구였다.
4. 기능이 준비되면 해당 줄의 상태를 바꾸고, 홈의 "곧 열려요"를 떼는 것까지 한 번에.

## 탭

| 탭 | 화면 |
|---|---|
| 실험실 | 홈 |
| 내 결과 | 받은 결과 전체 (MBTI 케미 포함), 최신순 |

"나" 탭은 시안에 있지만 **프로필 저장(2단계 뒤)** 전까지 넣지 않는다. 빈 탭을 만들지 않으려고.

## 홈

| 요소 | 누르면 | 비고 |
|---|---|---|
| 큰 문구 "너랑 나, 케미 몇 점?" | 없음 | 장식 |
| 버튼 "내 이름 케미부터" | 내 이름 케미 입력 (지금의 이름 진단 입력) | |
| 비커 마스코트 | 없음 | 장식 |
| MBTI 판의 유형(예: INFP) | MBTI 고르기, **"나"에 그 유형이 선택된 채로** | 전에 고른 내 유형이 있으면 그 유형이 맨 앞 |
| MBTI 판 "+13" | MBTI 고르기 (선택 없음, 저장된 내 유형은 미리 선택) | |
| 결과 카드 (기록이 있을 때) | 그 결과 화면 | 제목 "내 실험 기록", 최근 5개, 끝에 "전체 보기" → 내 결과 탭 |
| 결과 카드 (기록이 없을 때) | 그 검사 시작 화면 (예시와 같은 값으로 미리 채움) | 제목 "이런 결과가 나와요", 카드마다 "예시" 표시 |
| 우리 케미 | 우리 케미 입력 | 점수·해설 무료, 전체 리포트 ₩4,900 |
| 가족 케미 | 가족 케미 입력 | 점수·해설 무료, 전체 리포트 ₩5,900 |
| 이름 케미 | 이름 케미 입력 | 무료, 기기 계산 (소리 오행) |
| 아기 이름 찾기 | 작명 입력 | |

기존 "무료 체험 1회" 배지는 **뺀다**. 서버의 무료 체험은 '아기 이름(본인 사주) 1회'인데, 새 홈 맨 위 버튼은 내 이름 케미라서 배지를 보고 누른 사람이 엉뚱한 기능으로 간다. 무료인 것은 각 항목에 "무료"로 표시.

## MBTI 케미 (무료, 서버·AI 없음)

| 화면 | 요소 | 누르면 |
|---|---|---|
| 고르기 | 뒤로 | 들어온 곳 |
| | "나는" 16유형 | 선택 (다시 누르면 다른 유형으로 바뀜, 해제는 없음) |
| | "상대는" 16유형 | 선택 |
| | 하단 버튼 | 둘 다 고르기 전: 눌리지 않음, 문구 "두 유형을 골라 주세요" / 고른 뒤: "INFP × ENTJ 케미 보기" → 결과 |
| 결과 | 뒤로 | 고르기 (선택 유지 → 상대만 바꿔 다시 보기 쉽게) |
| | 공유(위 아이콘, 아래 버튼) | 공유 카드 이미지를 만들어 공유 시트 |
| | "생일까지 넣으면 진짜 케미" 카드 | 우리 케미 입력 |

- 점수·문구는 `mbti_chemi.dart`의 규칙표로 계산. **A×B와 B×A는 같은 점수**, 문구는 "나/상대" 자리에 맞게.
- 결과를 보면 기기에 기록(최근 30개) → 홈 "내 실험 기록"과 내 결과 탭에 나온다. 같은 조합을 다시 보면 새로 쌓지 않고 맨 위로.
- "나는"에서 고른 유형을 내 유형으로 기억 → 다음에 미리 선택.

## 내 이름 케미 / 아기 이름 (기존 흐름)

기존 이름 진단·작명 화면과 결제 흐름을 그대로 쓴다. 결과 카드의 점수는
진단 = `overallScore`(서버가 만든 실제 점수), 작명 = 첫 이름의 `score`.

## 이름 케미 (무료, 서버·AI 없음)

| 화면 | 요소 | 누르면 |
|---|---|---|
| 입력 | 내 이름 / 상대 이름 | 한글만. 입력하는 동안 글자마다 소리 오행 칩. 내 이름은 전에 넣은 걸 미리 채움 |
| | 하단 버튼 | 둘 다 한글 2~4글자 전: 눌리지 않음 "두 이름을 넣어 주세요" / 뒤: 결과 |
| 결과 | 공유(위·아래) | 스토리 카드 미리보기 → 이미지 공유 |
| | 다른 이름으로 다시 보기 | 입력에서 왔으면 돌아가기(이름 유지), 기록에서 열었으면 입력 화면 |

- 계산은 `data/name_chemi/name_chemi.dart`. 초성 → 오행(ㄱㅋ 목 / ㄴㄷㄹㅌ 화 / ㅇㅎ 토 / ㅅㅈㅊ 금 / ㅁㅂㅍ 수).
  점수 = 58 + 대표 기운 관계 + 오행 다양성 + 소리 흐름 (화면의 "점수 근거"와 같음). 순서를 바꿔도 같은 점수.
- 기록은 기기에만 (최근 30개), 홈 "내 실험 기록"·내 결과 탭에 나온다.
- 생일까지 넣는 사주 궁합은 우리 케미가 맡는다 (이름 케미에서 생일을 받지 않는 이유).

## 결과 화면 공통: "정확한데?"가 나오게 (MBTI·이름·우리·가족)

- **나는 이런 사람**(우리 케미) / **우리 집 역할**(가족 케미): 태어난 날의 천간(일간)으로 본 성격·역할.
- **둘 중 누가? / 우리 가족 중 누가?**: "먼저 연락하는 사람" 같은 질문에 이름으로 답하고, **근거를 같이** 보여 준다
  (MBTI: "E vs I", 사주: "화(火) 기운 3 : 1"). 같으면 음양으로, 그래도 같으면 막상막하·공동이라고 솔직하게.
- **케미 올리는 법**: 점수가 낮은 항목부터 최대 3개, 구체적인 행동으로. 약한 곳이 없으면 "지금 좋은 흐름 지키기".

## 가족 케미 (점수·해설 무료, 전체 리포트 유료)

| 화면 | 요소 | 누르면 |
|---|---|---|
| 입력 | 처음 세 칸 (나·엄마·아빠) | 나는 전에 넣은 정보로 미리 채움 |
| | 역할 알약 | 나·엄마·아빠·형제·자매·자녀·배우자·가족 중 고르기 |
| | 빼기(×) | 3명일 때는 없음 |
| | 가족 더하기 (n/5) | 5명이면 사라짐 |
| | "두 사람만 보려면 우리 케미로 →" | 우리 케미 입력 (이 화면을 바꿔서, 뒤로 가면 홈) |
| | 하단 버튼 | 시간 "알고 있음"인데 시진을 안 고른 사람이 있으면 눌리지 않음 |
| 결과 | 두 사람씩 줄 | 그 두 사람의 우리 케미 화면 (관계: 가족, **결제 칸 없음**, 우리 케미 기록에 안 남김) |
| | 전체 리포트 열기 | 결제 (`chemi_family`) → 검증 뒤 AI 리포트 → 기기 저장 |
| | "가족 사주에 맞는 아기 이름 찾기" | 작명 입력 |
| | 가족 바꿔서 다시 보기 / 돌아가기 | 입력(가족 유지) / 기록에서 열었으면 돌아가기 |

- 이름을 비우면 역할 이름으로 부르고, 겹치면 숫자를 붙인다 (형제, 형제2).
- 가족 점수 = 두 사람씩 본 우리 케미 평균 × 0.85 + 가족 오행 보너스(가진 오행 5가지 15 / 4가지 11 / 3가지 7 / 2가지 3). 화면 "점수는 이렇게 나왔어요"에 그대로.
- 기록은 기기에만 (최근 20개). 서버에는 결제할 때만 결과 자리를 만든다 → 재설치 뒤 결제한 결과는 복원.
